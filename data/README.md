# Данные

Исходный файл `test.csv` предоставлен автором исследования. Его внешний источник
и лицензия в ноутбуках не указаны. Локальная копия находится в `raw/test.csv`.

Из корня репозитория:

```bash
python -m src.prepare_data --input data/raw/test.csv
```

В `processed/` создаются:

| Файл | Содержание | Логика |
|---|---|---|
| `cleaned_types.parquet` | Очищенные типы, пропуски, пустые строки и столбцы | Ноутбук 1 |
| `train.parquet` | Первый период, около 70% уникальных заказов | Ноутбук 2 |
| `validation.parquet` | Следующие около 15% заказов | Ноутбук 2 |
| `test.parquet` | Последний период | Ноутбук 2 |

`test.csv` — весь исходный датасет, а `test.parquet` — отложенная выборка.
Полные данные исключены из Git. Для воспроизведения после клонирования нужен
исходный CSV или готовые Parquet-файлы в `processed/`.

Ожидаемые столбцы: `item_id`, `status`, `created_at`, `sku`, `price`, `qty_ordered`,
`grand_total`, `increment_id`, `category_name_1`, `sales_commission_code`,
`discount_amount`, `payment_method`, `Working Date`, `BI Status`, `MV`, `Year`,
`Month`, `Customer Since`, `M-Y`, `FY`, `Customer ID`.
Пустые `Unnamed: 21`–`Unnamed: 25` удаляются, если присутствуют.
Идентификаторы сохраняются строками, включая ведущие нули.

Границы разбиения определяются порогами 70% и 85% накопленных уникальных заказов
по `created_at`. В исследовании даты имеют дневную точность. Строки без даты
исключаются из выборок; их число выводится в консоль. Скрипт дополнительно проверяет
отсутствие заказов с несколькими датами и пустых выборок.
